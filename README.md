# QGIS Copilot

一个面向 QGIS 的开源 AI GIS 助手。

QGIS Copilot 允许用户直接在 QGIS 内通过自然语言理解项目、查询图层、执行空间分析和生成结果，而不要求用户理解 Agent、MCP、端口或外部客户端配置。

## 产品目标

- 在 QGIS 内提供直接可用的聊天入口；
- 用自然语言操作当前 QGIS 项目；
- 由 Agent 负责理解任务、调用工具和反馈结果；
- 对修改、删除、覆盖和执行代码等高风险操作提供明确确认；
- 支持多种模型来源，不绑定单一模型厂商；
- 以 QGIS 原生工具为核心，以 MCP 作为可选扩展能力；
- 面向 Windows、Linux、macOS 设计，尽量减少额外安装和手动配置。

## 当前产品定位

> QGIS Copilot 是一个在 QGIS 内运行的开源 AI GIS 助手，也是面向 QGIS 工作流的 MCP Host。

## 目标用户

- 想用自然语言完成常见 GIS 操作的 QGIS 用户；
- 不熟悉 PyQGIS、Processing 参数和 MCP 配置的初学者；
- 希望提高重复性 GIS 工作效率的专业用户；
- 希望通过 MCP 扩展 GIS 工具能力的开发者。

## 目标体验

```text
安装 QGIS Copilot 插件
    ↓
点击 AI 助手
    ↓
选择或配置模型
    ↓
输入自然语言任务
    ↓
查看执行计划
    ↓
确认后执行
    ↓
结果直接回到 QGIS 项目
```
